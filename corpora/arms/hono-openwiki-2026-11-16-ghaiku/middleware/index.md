- [Built-in Middleware Catalog](built-in-middleware.md) - Catalog of the first-party middleware under src/middleware, grouped by concern - authentication (basic, bearer, JWT, JWK), request and response security (CORS, CSRF, secure headers, IP restriction, body limit), response processing (compress, ETag, cache, serve-static, pretty-json), request handling (request-id, timeout, method-override, trailing-slash, language, combine, context-storage), observability (logger, timing), and rendering - with the key mechanisms, defaults, and failure responses of each.
