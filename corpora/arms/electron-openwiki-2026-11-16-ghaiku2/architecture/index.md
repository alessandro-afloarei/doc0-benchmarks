# Files

- [API Documentation and Typings](api-docs-and-typings.md) - How Electron's Markdown API docs in docs/api are the source of truth for the public surface, how they are parsed into electron-api.json and turned into electron.d.ts, how the typings and ts-smoke tests check the result, and how a new API is documented.
- [Chromium, Node, and Upstream Patches](chromium-and-upstream-patches.md) - How Electron layers its own changes onto Chromium, Node.js, V8, and other vendored dependencies, covering the patches/ directory and its .patches ordering, the apply and export tooling, the chromium_src GN overlay, and the rules for justifying a patch.
- [JavaScript API Layer](javascript-api-layer.md) - How the TypeScript sources under lib/ implement Electron's public modules for each process type, how webpack bundles them into per-process init scripts, how those scripts are embedded into the binary as natives, and how the electron module is assembled from lazy module lists.
- [Native Shell (C++)](native-shell.md) - How Electron's C++ shell is organized across shell/app, shell/browser, shell/renderer, and shell/common, how native objects are exposed to JavaScript through gin wrappers and linked Node bindings, and how platform-specific UI and behavior are split by directory.
- [Architecture Overview](overview.md) - System-level map of Electron, showing how Chromium, Node.js, V8, the C++ shell, the TypeScript runtime in lib/, the upstream patch set, and the docs and test toolchain fit together, and which process or layer owns each responsibility.
- [Process Model and IPC](process-model-and-ipc.md) - How Electron's browser, renderer, sandboxed renderer, utility, worker, and preload-realm processes are initialized, and how ipcMain, ipcRenderer, sendSync, invoke, and message ports move messages between them over Mojo and the internal IPC dispatch.
- [Security Model and Fuses](security-model-and-fuses.md) - Electron's security-relevant mechanisms, covering build-time fuses and how they are generated and read, the runtime web-preference defaults that set renderer isolation, the sandbox and preload restrictions, ASAR integrity checks, file-protocol privileges, and the renderer security warnings.
