# Files

- [API Documentation, Typings, and API History](api-docs-and-typings.md) - How the Markdown under docs/api is the source of truth for Electron's public API. Explains how it is parsed into electron-api.json, turned into electron.d.ts with @electron/typescript-definitions, type-checked by the ts-smoke suite, linted for code samples and API-history blocks, and what to change when adding or altering an API.
- [Building Electron with GN and Ninja](build-and-gn.md) - End-to-end build workflow for Electron. Covers the gclient checkout layout, the GN argument files under build/args, the BUILD.gn targets (electron, electron_lib, the bundle and fuse actions, and the dist zip targets), the TypeScript and webpack steps that compile lib/ into per-process bundles, the helper scripts under script/, and the platform prerequisites.
- [Chromium Upgrade and Patch Maintenance Workflow](chromium-upgrade-and-patch-workflow.md) - Operational workflow for moving Electron to a new Chromium, Node.js, or V8 revision. Covers changing the DEPS pins, reapplying the patch stack, exporting and importing patches, the patch-validation lint rules, and how CI detects patch drift, auto-commits repairs, and surfaces conflicts through problem matchers.
- [CI Pipelines and Release Automation](ci-pipelines.md) - The GitHub Actions workflows and composite actions that build, test, lint, and publish Electron, and the script/release tooling that prepares releases, triggers CI builds, validates and publishes release assets, and generates notes. Also notes the scheduled OpenWiki update workflow.
- [Linting and Formatting](linting.md) - The lint entry points in Electron. script/lint.js dispatches per language to ESLint, clang-format, cpplint, pylint-style checks, gn format, markdownlint, and the patch validator. The npm lint scripts, the docs-specific checks (remark, lint-roller, fiddles, ts-check, API history), and the git hooks and lint-staged rules that run them on commit all live here.
- [Test Suite (spec/) and Test Runners](testing-spec-suite.md) - How Electron's Mocha-based spec suite in spec/ is organized and run. Covers the spec/index.js bootstrap that runs the suite inside an Electron process, file discovery for *-spec.ts files, the disabled-test lists, fixtures and spec helpers, and the three runners (main spec runner, Node.js test runner, and nan native-module runner) driven by script/spec-runner.js and its siblings.
