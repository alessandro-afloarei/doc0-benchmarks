# Files

- [Entry Filters (Type, Extension, Size, Time, Owner)](entry-filters.md) - The filters fd applies after a name match, based on extension or metadata. Covers --type semantics including executable and empty, --extension matching, --size units, --changed-within/--changed-before time parsing, --owner user:group checks, and the order they run in and what they cost.
- [Ignore Rules and Traversal Controls](ignore-rules-and-traversal.md) - Which entries fd skips by default and how each ignore or traversal flag maps onto ignore::WalkBuilder. Covers hidden files, .gitignore, .ignore and .fdignore, the global fd/ignore file, --ignore-file, --exclude, --ignore-contain, depth limits, --prune, --follow, --one-file-system, --no-require-git and -u.
- [Output Formatting, Colors and Terminal Safety](output-formatting.md) - How fd prints each result. Covers the print_entry modes (--format template, LS_COLORS colorized, plain or raw bytes), color and hyperlink auto-detection, the default LS_COLORS theme, OSC 8 file:// hyperlinks, path separators and trailing slashes, ./ prefix stripping with dash safety, --print0, and how filenames and error messages are sanitized against terminal escape injection.
- [Pattern Matching](pattern-matching.md) - How fd turns the search pattern and any --and patterns into byte regexes. Covers regex, --glob, --fixed-strings and --exact modes, smart case detection from the regex syntax tree, filename versus --full-path matching, and the errors fd raises for patterns that could never match.
