# Files

- [Periodic Tasks: Beat and Schedules](beat-scheduler.md) - How celery beat schedules periodic tasks. Covers the Scheduler heap/tick loop, the shelve-backed PersistentScheduler, the Service run loop, beat embedded in a worker (-B), schedule types (interval, crontab, solar), timezone resets, and the beat_* settings.
- [Command-Line Interface](cli.md) - The click-based `celery` umbrella command. Covers the entry point and early eventlet/gevent patching, global options and their environment variables, app discovery for -A, the subcommands (worker, beat, events, inspect/control, call, purge, result, multi, and others), daemon options, and how user and preload options or plugin commands extend it.
- [Deployment, Daemonization and Packaging](deployment.md) - How Celery processes are run in production. Covers the platform layer (double-fork daemonization, pidfile locks, privilege dropping, root/pickle safety check), the init and supervision templates in extra/ (systemd, init.d, supervisord, launchd), the docker development environment, the sample Helm chart, and release tooling.
- [Events and Monitoring](events-monitoring.md) - How Celery's monitoring event stream works. Covers EventDispatcher publishing task-* and worker-* events to the celeryev exchange (with buffering and groups), worker heartbeats, EventReceiver's transient queues, the in-memory State model with out-of-order merging, snapshot cameras, and the curses/dump monitors.
