# Files

- [Concurrency Pools and Autoscaling](concurrency-pools.md) - The worker's execution pools in celery/concurrency. Covers pool selection and aliases, the BasePool contract and capability flags, the prefork pool (billiard, AsynPool with the event loop, child initializer, scheduling strategies, time limits, recycling by task count or memory), threads, solo, eventlet/gevent green pools, custom pools, and the autoscaler.
- [Consumer, Strategies and Task Requests](consumer-and-requests.md) - How a Celery worker receives task messages and turns them into executions. Covers the Consumer blueprint and its bootsteps (Connection, Mingle, Events, Gossip, Heart, Control, Tasks, DelayedDelivery, Evloop, Agent), prefetch/QoS, connection loss and recovery, the async and sync event loops, the per-task strategy (decoding, revocation, ETA, rate limits), and the Request object's acknowledgement, timeout, and failure semantics.
- [Remote Control and Inspection](remote-control.md) - How Celery broadcasts commands to workers over a kombu pidbox mailbox. Covers the client API (app.control, Inspect), the worker-side Panel command registry and handlers (revoke, rate_limit, time_limit, pool grow/shrink/restart, autoscale, add/cancel consumer, shutdown, stats and the dump_* inspections), revoke semantics and persistence with --statedb, and configuration and limits.
- [Worker Architecture and Bootsteps](worker-architecture.md) - How a Celery worker process is assembled and run. Covers the WorkController and its blueprint, the bootsteps framework (Blueprint, Step, StartStopStep, ConsumerStep, dependency ordering), the worker components (Timer, Hub, Pool, Beat, StateDB, Autoscaler, Consumer), the apps/worker.py program wrapper (banner, privilege check, signal handlers), and warm, cold, soft, and hard shutdown.
