# Files

- [Task Execution Tracing](execution-tracing.md) - How celery/app/trace.py runs a task body inside the worker. Covers the tracer built per task, request/task stacks, the order of signals, hooks, state writes and callback/chain dispatch, error-state handling (Retry, Reject, Ignore, failures), logging policy, deduplication of redelivered successes, fast_trace_task optimizations, internal errors, and memory-leak safeguards.
- [Task Messages, Protocol and Routing](messaging-and-routing.md) - How app.amqp turns a task call into a broker message. Covers the protocol v2 header/property/body layout (with v1 compatibility), countdown/ETA/expires conversion, the Queues table and missing-queue creation, the Router and task_routes formats, publish retry, publish signals and task-sent events, and native delayed delivery for RabbitMQ quorum queues.
- [Tasks: Definition, Invocation, Retries](task-lifecycle.md) - The Task class in celery/app/task.py. Covers lazy binding and configuration-derived defaults, annotations, the request Context, apply_async/delay/apply (eager) semantics including argument checking, retry and autoretry with backoff, replace and add_to_chord, update_state, lifecycle hooks, acknowledgement options, and the task states and predicate exceptions.
